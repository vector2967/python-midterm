노란 형광펜이 외울 부분. 가리기를 켜고 하나씩 눌러 확인하세요.

🖨️ print 인자

  • sep 기본값 = 공백 ' '
  • end 기본값 = '\n' (개행)
  • print('a','b') → a b / print('a''b') → ab
  • \ 줄 이어쓰기: 뒤에 공백도 오면 안 됨
  • '''…''' = 입력한 그대로 출력
  • 파일로 출력: print(x, file=f)

🔢 서식

  • %d 정수 · %f 실수(소수 6자리) · %s 문자열
  • %5.2f = 전체 폭 5, 소수점 2자리
  • '%09d' % 123 → 000000123
  • '{1} {0}'.format('a','b') → b a
  • f"{x=}" (x=1) → x=1
  • f"{1234567.89:,.2f}" → 1,234,567.89
  • f"{255:b}/{255:o}/{255:x}" → 11111111/377/ff
  • 'Hi'.zfill(5) → 000Hi, 'hi you'.capitalize() → Hi you

🧮 연산자 함정

  • 7 / 2 → 3.5, 7 // 2 → 3, 7 % 2 → 1
  • 100 / 2 → 50.0 (float)
  • -7 % 3 → 2 (부호는 제수를 따름)
  • -7 // 3 → -3 (내림)
  • 2 + 3 * 4 → 14, 2 ** 3 ** 2 → 512
  • 우선순위: ** > * / // % > + -
  • int(True) → 1, bool(0) → False
  • "*" * 3 → '***'

🔁 제어문

📂 파일 (7장)

  • "r" 읽기(파일 있어야 함), "w" 쓰기(기존 내용 삭제), "a" 추가
  • "rb"/"wb" = 이진 파일
  • readline()이 EOF에서 반환: 빈 문자열 ""
  • readline() 결과는 \n 포함
  • read() 전체 문자열 · readline() 한 줄 · readlines() 줄 리스트
  • write()는 줄바꿈 자동 추가 안 함, 인자는 문자열 하나
  • 빈 줄 생김 방지: rstrip()
  • Windows 경로: r"c:\dir\f.txt" 또는 \\
  • 오른쪽에서 1번만 분리: rsplit(" ", 1)
  • ord("A") → 65, chr(97) → 'a'
  • 위치 이동 seek(), 현재 위치 tell()
  • sys.argv[0] = 스크립트 이름, 실제 인자는 1번부터

🚨 예외 (7장)

  • 오류 대응 두 측면: 감지(detection)와 처리(handling)
  • 예외 발생 키워드: raise
  • 항상 실행되는 절: finally
  • 예외 없을 때만: else
  • 순서: try → except → else → finally
  • except 여러 개면 구체적인 것 먼저
  • 처리 안 된 예외는 호출자로 전파(propagate)
  • Tip 7.1: 문제 제기는 일찍, 처리는 늦게
  • Tip 7.2: 같은 try에 except와 finally 함께 쓰지 않기
  • with문 = try/finally를 자동화
  • 사용자 정의 예외는 Exception 상속
  • 없는 파일 IOError, int("abc") ValueError, 데이터 초과 RuntimeError(직접 raise)
  • 0으로 나누기 ZeroDivisionError, 없는 키 KeyError, 인덱스 초과 IndexError

🏛️ 클래스 기본 (9장)

  • 캡슐화 = 공용 인터페이스는 제공, 구현 세부는 숨김
  • 공용 인터페이스 = 클래스가 제공하는 모든 메소드의 집합
  • 생성자 이름: __init__, 클래스당 하나
  • 메소드 첫 파라미터: self (호출 대상 객체, 자동 전달)
  • private 관례: 이름 앞 밑줄 _ (강제 X)
  • 설정자(mutator) = 객체를 수정 (addItem, clear)
  • 접근자(accessor) = 수정 없이 조회 (getTotal)
  • Tip 9.1: 인스턴스 변수 private, 메소드 public
  • Tip 9.2: 인스턴스 변수는 생성자 안에서만 정의
  • CE 9.1: 생성자를 직접 다시 호출하지 말 것
  • 클래스 변수 = 클래스에 단 하나, 모든 객체 공유

🔗 설계 · 참조 (9장)

  • 설계 7단계 중 인스턴스 변수 결정 = 4단계 (메소드가 필요로 하는 정보 기준)
  • 테스터 4단계: 생성 → 호출 → 출력 → 기대 결과 출력
  • 단위 테스트 = 클래스를 격리해서 테스트
  • 객체 추적 카드: 앞면 메소드, 뒷면 인스턴스 변수
  • 변수는 객체의 메모리 주소를 담음(참조)
  • 같은 객체를 가리키는 두 변수 = 별칭(alias)
  • 같은 객체인지 검사: is / is not
  • None 객체의 메소드 호출 → AttributeError
  • 참조 없는 객체 제거: 가비지 컬렉터
  • BankAccount 1000→+500→출금2000→이자1% = 1504.90

➗ Fraction · 특별 메소드

  • x + y → __add__, x == y → __eq__, x < y → __lt__
  • float(x) → __float__, print(x) → __repr__
  • __eq__, __lt__로 유도 가능: !=, <=, >, >=
  • x >= y ⇔ not x < y, x > y ⇔ y < x
  • Fraction(-2, -4) → 1/2, Fraction(0, 15) → 0/1, Fraction(2, -8) → -1/4
  • 분모 0 → ZeroDivisionError
  • 약분 알고리즘: 유클리드 호제법(gcd)
  • Fraction은 불변 → 연산은 새 객체 반환

🌳 상속 기본 (10장)

  • 상속 문법: class Sub(Super):
  • 대체 원리: 상위 자리에 하위 객체 사용 가능 (반대 불가)
  • 다이어그램 화살표는 상위 클래스를 향함
  • 모든 클래스의 뿌리: object
  • 하위 생성자에서 가장 먼저: super().__init__()
  • 상위 private 변수는 공용 인터페이스(setAnswer 등)로 접근
  • '하위'인 이유: 집합론의 부분집합
  • 값만 다르면 인스턴스 변수, 동작이 다르면 하위 클래스
  • 같은 이름 상위 메소드를 self로 호출 → 무한 재귀

🎭 다형성 · 추상 (10장)

  • 오버라이드 = 상속받은 메소드에 새 구현 제공
  • 호출될 메소드가 실행 시간에 실제 타입으로 결정 = 동적 메소드 검색
  • 다형성 = "여러 형태", 같은 요청을 각자의 방식으로
  • 새 문제 유형 추가 시 presentQuestion은 수정 불필요
  • isinstance(q, Question): 하위 클래스 인스턴스도 True
  • CE 10.3: isinstance 타입 테스트로 분기하지 말 것
  • 추상 메소드 표현 관례: raise NotImplementedError
  • 추상 메소드 1개 이상 = 추상 클래스, 없으면 실제(concrete) 클래스
