print 기본과 sep · end · file

i, f, s = 123, 3.14, 'Hello'

print(f"{1234567.8912:,.2f}")  # 1,234,567.89 (천 단위 콤마)
s = "Python"

2. 홀짝 합계와 프로그래밍 기초 2주

Week2_홀수,짝수합.pdf — 문제: 1~100의 홀수 합(2500)과 짝수 합(2550)

여러 가지 풀이

방법아이디어반복문 수시간
1. 단일 for + if한 번 순회하며 두 합을 동시에 누적. odd_sum = total - even_sum으로도 가능1O(n)
2. range(step) 두 개range(2,101,2), range(1,101,2) — if 불필요2O(n)
3. 등차수열 공식n*(n+1)//2 — 반복문 없음0O(1)
4/5. 리스트 컴프리헨션필터링(길이 줄어듦) / 마스킹(조건 밖은 0, 길이 유지)1(암묵적)O(n)
6. 객체지향입력(__init__)·처리(calculate_sums)·출력(display_results) 분리1(암묵적)O(n)
n = 100
total = n * (n + 1) // 2           # 5050
even_sum = 2 * (50 * 51 // 2)      # 2+4+...+100 = 2(1+...+50) = 2550
odd_sum = total - even_sum         # 2500

even_sum = sum([i for i in nums if i % 2 == 0])              # 필터링
even_masked = [i if i % 2 == 0 else 0 for i in range(1, 101)] # 마스킹

일반화: 100을 하드코딩하지 말고 def sum_odd_even_formula(n)처럼 매개변수로. 반복문 버전과 공식 버전의 결과가 일치하는 것 자체가 정확성 검증. timeit으로 측정하면 n이 10,000배 → loop 시간도 약 10,000배(O(n)), formula는 거의 그대로(O(1)).

흔한 버그와 함정

  1. 경계값(off-by-one): range(1, 100)은 100을 포함하지 않는다.
  2. = vs ==: 대입과 비교 혼동.
  3. 누적 변수 초기화 누락: 이전 값이 결과를 오염.
  4. / vs //: 100 / 2 → 50.0(항상 float), //는 몫(int).
⚠️
이 버그들은 모두 프로그램이 멈추지 않고 실행된다 → 문법 오류가 아닌 논리·의미 오류라서 위험.

  • split()(인자 없음): 공백 기준, 연속 공백은 하나로 처리. split(":")처럼 sep 지정 시 연속 구분자는 빈 문자열 생김

  • 문자 단위: read(1), ord("A") → 65, chr(65) → "A"
  • 레코드: 한 줄+구분자면 line.split(":"), 필드가 여러 줄이면 readline()을 필드 수만큼

def __add__(self, rhs):     # a/b + c/d = (a·d + b·c) / (b·d)
    num = self._numerator * rhs._denominator + self._denominator * rhs._numerator
    den = self._denominator * rhs._denominator
    return Fraction(num, den)       # 새 객체 반환 (약분은 생성자가)

def __lt__(self, rhs):      # a/b < c/d ⇔ a·d < c·b
    return self._numerator * rhs._denominator < self._denominator * rhs._numerator

# ==, < 만 있으면 나머지 유도
def __ne__(self, rhs): return not self == rhs
def __le__(self, rhs): return not rhs < self
def __gt__(self, rhs): return rhs < self
def __ge__(self, rhs): return not self < rhs

def __repr__(self):
    return str(self._numerator) + "/" + str(self._denominator)

        return super().weeklyPay(hoursWorked) + self._weeklyBonus

기하학적 형상 계층 (10.6)

GeometricShape
 ├─ Line ── Arrow
 ├─ Rectangle ── Square
 ├─ Oval ── Circle
 ├─ Polygon ── Triangle, RegularPolygon
 └─ Group
  • GeometricShape: _x, _y(둘러싼 박스 왼쪽 위), _fill(None), _outline("black"). getWidth/getHeight 기본값 0. draw는 색 설정만 → 하위에서 super().draw(canvas) 후 실제 그리기
  • Square: super().__init__(x, y, size, size) — 더 편리한 인터페이스를 위해 다른 클래스를 감싸는 포장 클래스(wrapper class)
  • Line: super().__init__(min(x1,x2), min(y1,y2)) (더 작은 좌표가 왼쪽 위). width=abs(endX-startX). moveBy 오버라이드로 시작·끝점도 이동
  • Group: 직접 그리지 않는 컨테이너. getWidth = max(각 도형의 x + width). Group 안에 Group 가능
